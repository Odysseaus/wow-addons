# Third-party material in Dark Matter

## OpenMap (MIT)

Dark Matter 0.5.1.4 reuses, from OpenMap v0.7.2-beta (<https://www.curseforge.com/wow/addons/openmap>, project 1735937,
"OpenMap contributors"):

- **`Data_Minimap.lua`**: OpenMap's `Data/Minimap.lua` table of the game's minimap tile file IDs (generated by OpenMap's
  `tools/map-data/minimap.py` from client build 1.60.1.70245). Only the variable name was changed.
- **Ideas from OpenMap's `Map/Close.lua`**, re-implemented in Dark Matter's own code (`MapCloseUp.lua`): the minimap
  tile grid (64 x 64 tiles of 533.33 yards per continent, tile x = 32 - worldY / 533.33, tile y = 32 - worldX / 533.33),
  the fade-in points (OpenMap's zoom 20-34x mix-in and 30-48x take-over, expressed in Dark Matter as screen pixels
  per yard: 0.20-0.34 and 0.30-0.48), the 64-tile limit, the parchment tint (1, 0.93, 0.80) and the 0.35 desaturation.

**Not used:** none of OpenMap's textures. OpenMap's own `Media/Textures/NOTICE.md` says they are cut from Blizzard's
art or painted by a named artist and are *not* covered by its MIT licence. Dark Matter does not ship, copy or
reference them, and does not need OpenMap to be installed.

## Blizzard Entertainment

Every map picture, minimap tile and stock UI texture Dark Matter shows is loaded from the game client at runtime by
path or file ID. None of them is copied into the addon.

## Dark Matter's own art

The close-up paper grain on the Map tab is Dark Matter's own generated parchment (`Media/wow-parchment.tga`, made for the
previewer mockup; no game art), drawn faintly over the map.
